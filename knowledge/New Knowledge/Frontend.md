# Frontend - Phát triển giao diện Web & UI

## Khái niệm
Khối kiến thức **Frontend** tập trung vào xây dựng giao diện người dùng tương tác trên nền tảng web, bao gồm HTML5, CSS3, JavaScript/TypeScript, kiến trúc Single Page Application (SPA), state management, component architecture và tích hợp với backend RESTful API.

## Các môn học trong chương trình FPTU SE:
- [[Mon hoc/WED201c - Thiết kế web|WED201c]]: Nhập môn thiết kế giao diện web với HTML5, CSS3, Responsive Design và JavaScript cơ bản.
- [[Mon hoc/FER202 - Phát triển web Front-End với React|FER202]]: Xây dựng ứng dụng web hiện đại với React, React Hooks, JSX, Router và State Management.
- [[Mon hoc/WDU203c - Thiết kế trải nghiệm người dùng|WDU203c]]: Nghiên cứu tâm lý học người dùng, thiết kế wireframe, prototype trên Figma và đánh giá khả năng sử dụng (usability).
- [[Mon hoc/SBA301 - Tích hợp ứng dụng trang đơn với Spring Boot|SBA301]]: Kết nối frontend SPA với hệ thống dịch vụ backend Spring Boot.
