# Cơ sở dữ liệu - Database Systems

## Khái niệm
Khối kiến thức **Cơ sở dữ liệu** bao gồm thiết kế mô hình dữ liệu quan hệ (ERD), chuẩn hóa dữ liệu, ngôn ngữ truy vấn có cấu trúc SQL, transaction (ACID), chỉ mục (index), tối ưu hóa hiệu năng cơ sở dữ liệu và các hệ quản trị CSDL NoSQL phân tán.

## Các môn học liên quan:
- [[Mon hoc/DBI202 - Các hệ cơ sở dữ liệu|DBI202]]: Thiết kế hệ cơ sở dữ liệu quan hệ và lập trình SQL Server.
- [[Mon hoc/SDN302 - Phát triển Server-Side với NodeJS, Express và MongoDB|SDN302]]: Tích hợp cơ sở dữ liệu NoSQL (MongoDB / Mongoose) trong ứng dụng backend.
- [[Mon hoc/PRJ301 - Phát triển ứng dụng Java web|PRJ301]]: Kết nối JDBC và thao tác dữ liệu quan hệ trong ứng dụng web Java.
- [[Mon hoc/DBM301 - Khai phá dữ liệu|DBM301]]: Khai phá tri thức từ các kho dữ liệu lớn (data warehouse) và cơ sở dữ liệu.
