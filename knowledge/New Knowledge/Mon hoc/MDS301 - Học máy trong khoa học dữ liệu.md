### Mô tả

1. This course introduces the core concepts and practical techniques of machine learning for data science through practical, hands-on work with Python. 2. Students will learn how to preprocess and analyze data, implement common machine learning algorithms, and evaluate model performance using appropriate metrics. 3. Using modern tools such as Scikit-Learn and PyTorch, student will practice solving real data problems including prediction, classification, clustering and basic deep learning.4. Additionally, students will gain basic experience deploying trained models through simple APIs and interpreting predictions with attention to ethical considerations.

### Thời lượng

Study hour (150h) = 45h contact hours + 1h final exam + 104h self-study
