### Mô tả

This course tackles all the problems related to NodeJS-based web servers. Contents to be implemented include:  
- Overview of Web protocols: HTTP and HTTPS.
- Introduction of NodeJS and frameworks such as ExpressJS, NestJS, Hono to build a web server.
- Introduction of simple templating languages such as EJB and HandleBar .
- Deploy the application on a web server with basic CRUD operations. Work with NoSQL databases, specifically MongoDB and Mongoose, to access MongoDB from NodeJS.
- Overview of REST and building a RESTful API.
- Learn Authentication and security-related issues for web applications.
- Integrate React app with server NodeJs
- Deploy server-based applications with Hosting Services
