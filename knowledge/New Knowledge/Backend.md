# Backend - Phát triển Server-Side

## Khái niệm
**Backend** là phần quan trọng của hệ thống phần mềm phụ trách xử lý logic nghiệp vụ, quản lý cơ sở dữ liệu, bảo mật, xác thực người dùng và cung cấp các dịch vụ API (RESTful, GraphQL, WebSockets) cho các ứng dụng client (Frontend, Mobile, IoT).

## Các môn học trong chương trình FPTU SE liên quan đến Backend:
- [[Mon hoc/SDN302 - Phát triển Server-Side với NodeJS, Express và MongoDB|SDN302]]: Phát triển dịch vụ máy chủ bằng Node.js, Express và cơ sở dữ liệu NoSQL MongoDB.
- [[Mon hoc/PRJ301 - Phát triển ứng dụng Java web|PRJ301]]: Xây dựng ứng dụng web Java theo mô hình MVC, Servlet, JSP và kết nối JDBC.
- [[Mon hoc/HSF302 - Làm việc với Spring Framework|HSF302]]: Phát triển backend doanh nghiệp mạnh mẽ với Java Spring Framework, Spring Boot và Hibernate.
- [[Mon hoc/SBA301 - Tích hợp ứng dụng trang đơn với Spring Boot|SBA301]]: Xây dựng backend RESTful API Spring Boot tích hợp với SPA frontend.
- [[Mon hoc/PRN222 - Lập trình ứng dụng đa nền tảng nâng cao với .NET|PRN222]]: Phát triển ứng dụng và dịch vụ backend trên nền tảng .NET hiện đại.
- [[Mon hoc/DBI202 - Các hệ cơ sở dữ liệu|DBI202]]: Nền tảng thiết kế dữ liệu, truy vấn SQL và tối ưu hóa hệ quản trị CSDL cho các hệ thống backend.
