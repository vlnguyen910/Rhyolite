### 🎯 Chuẩn đầu ra (CLO)
| No. | Tên LO | CLO Chi tiết |
| --- | --- | --- |
| 1 | CLO1 | Manipulate logical expressions and use logic for inference	<br>LO1.1	Determine the truth value of a proposition; check if two propositions are equivalent; translate between logical expressions and sentences for propositional logic.<br>LO1.2	Determine the truth value of a proposition; check if two propositions are equivalent; translate between logical expressions and sentences for predicate logic. <br>LO1.3	Manipulate logical expressions with nested quantifiers.<br>LO1.4	Recognize the inference rules used in a valid statemment; use inference rules to draw conclusions; check if a statement is valid. |
| 2 | CLO2 | Perform basic operations on sets, functions and sequences	<br>LO2.1	Distinguish basic terminologies in set theory; find the power set and cartersian product; represent a subset using binary bits.<br>LO2.2	Perform operations on sets; check if two sets are equal.<br>LO2.3	Determine if a given rule represents a function; perform operations on functions and manipulate functions inlvolving the floor and the ceiling functions. <br>LO2.4	Determine if a function is one-to-one, onto or a bijection, and describe how these properties can be used to compare two sets.<br>LO2.5	Find a formula for a sequence; evaluate a finite sum with a possible use of special summations. |
| 3 | CLO3 | Analyze basic algorithms written in pseudo codes and determine their complexities	<br>LO3.1	Determine if a procedure is an algorithm; work out basic algorithms written in pseudocodes including searching, sorting and  greedy algorithms.<br>LO3.2	Find big-O, big-Omega and big-Theta estimates of a function; describe complexity of an algorithm. |
| 4 | CLO4 | Discuss applications of modular arithmetic and analyze algorithms on integers	<br>LO4.1	Perform integer division and modular arithmetic; apply congruence in generating pseudorandom numbers and in cryptology. <br>LO4.2	Find the base b expansion of an integer; perform binary operations and modular exponentiation on integers. <br>LO4.3	Check if a number is prime and find prime factorization of an integer; find greatest common divisor and least common multiple. |
| 5 | CLO5 | Use induction and recursive definition to prove a statement or to describe an object, and write recursive algorithms	<br>LO5.1	Prove mathematical statements by induction. <br>LO5.2	Manipulate sequences and sets defined by recursion. <br>LO5.3	Work out recursive algorithms, including the mergesort algorithm; distinguish between iterative and recursive algorithms. |
| 6 | CLO6 | Solve counting problems	<br>LO6.1	Use basic rules for counting<br>LO6.2	Use recurrence relations for counting, including divide-and-conquer recurrence relations. |
| 7 | CLO7 | Analyze the structure of a graph and find shortest paths in a weighted graph	<br>LO7.1	Classify and describe a graph; use hand-shaking theorem to analyze a graph; identify special graphs including bipartite graphs.<br>LO7.2	Represent a graph using incidence and adjacency matrices; determine if two graphs are isomorphic.<br>LO7.3	Check connectivity of a graph and identify its connected components; count paths in a graph.<br>LO7.4	Determine if a graph has Euler/Hamilton paths/circuits; find Euler and Hamilton paths/circuits in a graph. <br>LO7.5	Run Dijsktra's algorithm to determine the shortest paths and the shortest distance in a weighted graph. |
| 8 | CLO8 | Analyze the structure of a tree and describe algorithms using trees	<br>LO8.1	Check if a graph is a tree, and identify basic terminologies of a tree; use properties of m-ary trees to solve problems.<br>LO8.2	Build binary search trees and decision trees; analyze complexities of algorithms described using binary search trees and decision trees.<br>LO8.3	Recognize and construct prefix codes; build optimal trees using Huffman coding.<br>LO8.4	Traverse a tree and use tree traversal to generate notations; evaluate prefix and postfix expressions.<br>LO8.5	Run Depth-first search and Breadth-first search algorithms to find spanning trees <br>LO8.6	Find minimum spanning trees using Prim, Kruskal,... algorithms |
