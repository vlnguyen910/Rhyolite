### 🎯 Chuẩn đầu ra (CLO)
| No. | Tên LO | CLO Chi tiết |
| --- | --- | --- |
| 1 | CLO1 | Understand Core Concepts: Explain fundamental machine learning principles of machine learning, distinguish between supervised, unsupervised, and reinforcement learning, and describe the end-to-end ML workflow. |
| 2 | CLO2 | Prepare and Analyze Data: Proficiently preprocess datasets, perform exploratory data analysis, and engineer relevant features to support effective model training. |
| 3 | CLO3 | Implement and Train Models: Implement and train a variety of key machine learning algorithms - including linear models, tree-based ensembles, and clustering methods - using standard Python machine learning libraries. |
| 4 | CLO4 | Evaluate and Validate Models: Select and use appropriate metrics to evaluate model performance, diagnose issues such as overfitting or underfitting, and validate model performance using techniques like cross-validation. |
| 5 | CLO5 | Apply Neural Networks: Understand the fundamentals of neural networks and build/train deep learning model using modern frameworks such as PyTorch for tasks including image classification. |
| 6 | CLO6 | Deploy and Interpret Models: Demonstrate basic model deployment by exposing a trained model through a simple API and interpret model predictions while recognizing ethical and data bias considerations. |
| 7 | CLO7 | Integrate ML solution into software system: Design, implement, and integrate a complete ML solution into a software system, including proper documentation, testing, and API deployment following software engineering best practices. |
