| No. | Tên LO | CLO Chi tiết |
| --- | --- | --- |
| 1 | CLO1 | Be able to explain what is involved in UX research, including conducting interviews, evaluating systems, and analyzing systems using principles of good design |
| 2 | CLO2 | Be able to describe about the work involved in UX Design, including the generation of promising design solutions and the creation of prototypes at multiple levels of fidelity |
| 3 | CLO3 | Be able to describe numerous techniques to gather data from and about users |
| 4 | CLO4 | Know how to design and conduct tests with users |
| 5 | CLO5 | Be able to apply techniques such as sketching, scenario development, storyboarding, and wireframing |
| 6 | CLO6 | Know how to turn wireframes and interaction architecture into interactive prototypes that can be tested with prospective users and iteratively refined into a high quality design |
| 7 | CLO7 | Be able to describe techniques for gaining UX insights from large numbers of users, including web analytics, A/B testing, and remote unmoderated studies |
| 8 | CLO8 | Know how to design and carry out an integrated multi-phase user experience research and design project |
