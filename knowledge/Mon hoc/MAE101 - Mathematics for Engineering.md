### 🎯 Chuẩn đầu ra (CLO)
| No. | Tên LO | CLO Chi tiết |
| --- | --- | --- |
| 1 | CLO1 | Describe basic properties and find the limit of a function<br>LO1.1	Find the domain, range, zeros and analyze the symmetry of the graph; create new functions from old functions.<br>LO1.2	Find the slope and write an equation of a line; describe how a function changes under graph translations.<br>LO1.3	Compute the limit of a function using graphs and limit laws, including the Squeeze's Theorem.<br>LO1.4	Find limits at infinity and infinity limits, and apply in finding asymptotes of a function.<br>LO1.5	Identify where a function is continuous; use the Intermedia Value Theorem to show that an equation has a solution. |
| 2 | CLO2 | Calculate derivatives of a function<br>LO2.1	Find the average rate of change; identify derivative as the limit of a difference quotient. <br>LO2.2	Recognize derivative as the instantaneous velocity and the slope of tangent lines.<br>LO2.3	Find derivatives using basic formulas and the sum, difference, product, quotient, chain rules. |
| 3 | CLO3 | Use derivatives to analyze a function and to solve applications<br>LO3.1	Use implicit differentiation to find derivatives and to solve related rates problems.<br>LO3.2	Find linear approximation of a function; calculate differentials and apply in calculating errors of approximation.<br>LO3.3	Apply Rolle's Theorem and Mean Value Theorem to a function; find critical numbers and absolute extrema of a function. <br>LO3.4	Identify local extrema, and describe the monotonicity of a function; solve optimization problems.<br>LO3.5	Recognize acceleration as second derivative; determine inflection points and describe the concavity of a function.<br>LO3.6	Use Newton method to approximate solutions of an equation. |
| 4 | CLO4 | Calculate integrals and find area under the graph of a function<br>LO4.1	Use Riemann sums to approximate area; recognize area as a definite integral which is the limit of Riemann sums.<br>LO4.2	Apply the Fundamental Theorems of Calculus to find derivatives of integrals, and to evaluate definite integrals. <br>LO4.3	Recognize indefinite integrals as anti-derivatives; find integrals using basic formulas and the techniques of substitution and integration by parts.<br>LO4.4	Use integration to solve applications and to compute the average value of a function. <br>LO4.5	Approximate definite integrals using Midpoint, Trapezoidal and Simpson rules. <br>LO4.6	Determine if an improper integral converges. |
| 5 | CLO5 | Solve a system of linear equations using Gaussian elimination<br>LO5.1	Identify if a matrix is in echelon forms; carry a matrix into an echelon using row operations; calculate the rank of a matrix. <br>LO5.2	Use echelon matrices to solve/describe the solution set of a linear system. |
| 6 | CLO6 | Perform basic operations on matrices and manipulate matrix transformations<br>LO6.1	Perform addition, scalar multiplication and transpose of matrices; verify if a matrix is symmetric.<br>LO6.2	Multiply two matrices of appropriate sizes; transform between a linear system and a matrix equation.<br>LO6.3	Determine the matrix of a linear transformation; use properties of linear transformations in solving problems. |
| 7 | CLO7 | Find the determinant, inverse and diagonalization of a matrix<br>LO7.1	Compute the cofactors and the determinant of a matrix; analyze determinants in relation with row/column operations.<br>LO7.2	Check if a matrix is invertible; find the adjugate and the inverse of a matrix; use properties of inverses and determinants in solving problems.<br>LO7.3	Solve a system of linear equations using inverse matrices or Cramer's rule.<br>LO7.4	Find the characteristic polynomial, eigenvalues and eigenvectors to diagonalize a matrix; check if a matrix is diagonalizable. |
| 8 | CLO8 | Manipulate vector operations and linear transformations in R^3.<br>LO8.1	Manipulate vector operations; find equations of lines. <br>LO8.2	Compute the dot product and the angle between two vectors; find the projection of a vector on another vector and manipulate equations of planes.<br>LO8.3	Compute the cross product; analyze areas and volumns in relation with dot and cross products.<br>LO8.4	Determine linear transformations in R^3 and discuss applications in computer graphic. |
| 9 | CLO9 | Find the dimension and bases of a subspace<br>LO9.1	Determine if a subset of vectors is a subspace; describe the subspace spanned by a set of vectors.<br>LO9.2	Check if a set of vectors are independent; determine if a set of vectors form a basis.<br>LO9.3	Find a basis and the dimension of a subspace; analyze the rank in relation with the dimension of the column, row and the null space of a matrix.<br>LO9.4	Compute dot product and length of vectors; check if a set of vectors are orthogonal or orthonormal; write a vector as a linear combination of an orthogonal basis. |
