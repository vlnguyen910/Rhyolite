| Mô tả: | The capstone project provides students important skills and initial experiences in participating in the software projects. Student can apply knowledges they have learned to the real current projects include:<br>- Experiencing across all project phases: requirement, design, coding, testing and release<br>- Finding out and using the templates and composing documents for each project stage<br>- Using knowledges of technology that have been taught<br>- Having the opportunity to research and apply new technologies<br>- Practicing teamwork and how to interact with colleagues in a project implementation process<br>- Ensuring the proper implementation of quality requirements and schedule<br>- Doing troubleshooting<br><br>With the team size of 4-5 members, the output product size are required to be equivalent to 20-25 medium use cases (3-7 transactions for each use case; action buttons on the screen, end user interactions to the software screens/functions or database transactions can be counted as transaction)<br><br>The capstone project provides students, working in groups, with a significant project experience in which they can integrate much of the material they have learned in their program, including matters relating to requirements, design, implementation, human factors, professionalism, and project management. Students should be expected to deliver one or several iterations of a software system, along with all artifacts appropriate to the process model they are using. These would likely include <br>a) Project management Plan (perhaps updated regularly), <br>b) Software Requirements Specifications (SRS)<br>c) Software Design Documents (SDD)<br>d) Test Plan and other Test Documentation (STD)<br>e) Software package & the user guides (package content, installation guide & user manuals)<br><br>All the documents in the project implementation process and the progress reports are required to write in English. |
